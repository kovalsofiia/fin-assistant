# Питання до бази практики (для звіту, пункти 1–2 програми)

Список підготовлено для отримання реальних даних від бази практики — без відповідей ці
розділи звіту заповнити неможливо (вигадувати факти про компанію не можна).

## Пункт 1. Організаційна та IT-інфраструктура бази практики

**Структура підприємства/ФОП, основні напрями діяльності**
1. Юридична форма: ФОП якої групи? Рік реєстрації? Основний КВЕД (вид діяльності)?
2. Чим саме займається компанія — розробка й продаж ПЗ (fin-assistant як продукт для
   клієнтів), чи це внутрішній інструмент для власного обліку ФОП, чи щось інше?
3. Чи є наймані працівники? Скільки, на яких посадах (розробка, підтримка, продажі)?
4. Хто приймає рішення щодо IT та цифровізації — ви особисто, окрема людина, підрядник?

**Підрозділи/виконавці, що забезпечують обробку даних, інформатизацію, цифровізацію**
5. Хто відповідає за розробку й підтримку fin-assistant (ви, команда, підрядники)?
6. Хто веде бухгалтерію — самостійно, бухгалтер на аутсорсі, спеціалізований сервіс?
7. Чи є інші люди/ролі, залучені до роботи з даними (аналітика, підтримка клієнтів тощо)?

**Використовувані інформаційні системи, ПЗ, серверне та мережеве обладнання**
8. Окрім fin-assistant, які ще системи використовуються в роботі (бухгалтерське ПЗ,
   банк-клієнт, CRM, месенджери для клієнтів/команди)?
9. Де розміщується інфраструктура (хмара — який провайдер хостингу/бекапів, чи власні
   сервери)? Supabase — єдина БД, чи є ще щось?
10. Чи є вимоги/обмеження щодо ІТ-інфраструктури (безпека даних клієнтів, резервне
    копіювання, доступність)?

## Пункт 2. Економіко-правове підґрунтя діяльності

**Система оподаткування**
11. Якої групи ФОП (1/2/3)? Спрощена чи загальна система?
12. Чи є платником ПДВ?
13. Чи є особливості/пільги щодо ЄСВ (наприклад, ФОП з інвалідністю, суміщення з
    основним місцем роботи тощо)?

**Договірні відносини**
14. Як оформлені відносини з розробниками/практикантами: трудовий договір,
    цивільно-правовий (ЦПХ), фриланс без договору?
15. Чи існує NDA або угода про конфіденційність щодо коду, даних клієнтів чи бізнес-логіки?
16. **Письмовий дозвіл** на використання коду fin-assistant і результатів практики в
    звіті/кваліфікаційній роботі (для навчальних цілей, без реальних даних користувачів) —
    чи можна отримати від вас підтвердження в довільній формі (email достатньо)?

**Бухгалтерський облік та податкова звітність**
17. Хто веде облік і готує звітність (ви самі, бухгалтер, сервіс на кшталт М.E.Doc)?
18. Яка періодичність подання звітності (щоквартально для 3-ї групи, раз на рік для 1–2)?
19. Чи використовується сам fin-assistant для ведення власного обліку ФОП, чи це окремо
    від того, що продається/розробляється?

---

*Примітка для звіту:* пункт 4 програми практики («перспективи цифровізації») можна
заповнити на основі відповідей на ці питання плюс уже готового технічного матеріалу
(чат-агент, автоматизоване тестування) — окремих запитань до бази для нього не потрібно.
